# 104 — Algorithms with invalid ranges or iterators

| Case | Violated precondition |
| --- | --- |
| `01-copy-too-small` | The output range must have room for every element written. |
| `02-mismatched-containers` | `[first, last)` must be a range in one container. |
| `03-unsorted-binary-search` | The range must be partitioned for the searched value. |
